UncheckedIOException
    Type: UncheckedIOException is an unchecked exception because it extends RuntimeException. The compiler does not enforce handling or declaration for it.
    Usage: It was introduced in Java 8 primarily to wrap an IOException in scenarios where checked exceptions are inconvenient, such as in Java Stream operations or lambda expressions.
    Function: It serves to propagate an I/O error without cluttering the code with try-catch blocks or throws clauses in every method along the call stack. It still contains the original IOException as its "cause", which can be retrieved using the getCause() method if needed at a higher level of the application.
